# Skills Index

Leesbaar overzicht van alle skills in deze library. Bij nieuwe skill:
voeg een regel toe en update `library.yaml`.

| Skill | Wanneer gebruiken | Kernidee |
|---|---|---|
| [plan-feature](skills/plan-feature.md) | Vóór niet-triviale wijzigingen | Intent → stappenplan → akkoord → code |
| [systematic-debug](skills/systematic-debug.md) | Bij bug of test-failure | Reproduceer → hypothese → één ding veranderen |
| [code-review](skills/code-review.md) | Vóór commit of PR | Correctheid, leesbaarheid, simplify, security, tests |
| [verify-before-done](skills/verify-before-done.md) | Vóór "klaar" claimen | Bewijs per claim: output, curl, screenshot |
| [commit-netjes](skills/commit-netjes.md) | Bij elke commit | Eén doel per commit, conventional message, geen `git add .` |
